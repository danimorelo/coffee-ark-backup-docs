Use & limits

A useful copy.
Not a recovery promise.

These notes describe a private, single-owner Ubuntu utility. They do not offer a public backup service, accounts, subscriptions, or service-level commitments.

Intended use

The utility creates encrypted database snapshots, uploads them to its own private Drive folder, and checks file metadata and downloaded encrypted bytes. It uses only the requested https://www.googleapis.com/auth/drive.file permission for app-created or explicitly selected files.

There is no automated sharing or deletion. The Google scope is not immutable or append-only; an authorized owner or application may still be able to change or remove files.

Availability is not guaranteed

Backups depend on Ubuntu, the database, network access, available storage and valid Google authorization. Schedules may be missed and uploads may fail. No guaranteed schedule, recovery point, or successful recovery is offered.

A downloaded ciphertext hash checks transport integrity. It does not prove that a database can be restored; recovery requires separate testing and the separately retained recovery identity.

A database snapshot is not everything

This is not a complete hosted-platform backup. Storage object bytes and hosted configuration are excluded. Other services, external credentials and deployment configuration require their own recovery arrangements.

The owner stays in control

The owner is responsible for keeping the recovery identity separate from Ubuntu and Drive, reviewing backup age and failures, checking available storage, and testing recovery. Snapshots remain until the owner removes them.

Google authorization can be revoked without deleting existing backups. Google and GitHub provide their own account, storage and hosting services under their own policies. No broader legal compliance guarantee is made here.
