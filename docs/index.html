Coffee Ark Ubuntu Backups is a single-owner utility that creates encrypted database snapshots on Ubuntu and delivers them to its own private Google Drive folder.

This is not the Coffee Ark pantry application, a signup page, or a public backup service. These pages simply explain the private integration.

A simple path to a separate copy.

  1. Make a snapshot

    The utility produces a bounded database backup on Ubuntu.

  2. Encrypt first

    Encryption happens before upload. The recovery identity is kept separately from Ubuntu and Drive.

  3. Check delivery

    File metadata and downloaded encrypted bytes are checked for reconciliation and transport verification.

A deliberately limited Google permission.

The requested scope is https://www.googleapis.com/auth/drive.file. It covers files created by the app or explicitly selected for it. This utility creates its own private folder and does not browse unrelated Drive files.

This scope is not read-only, immutable, or append-only. Limited access is not a promise that stored snapshots cannot be changed or removed.

Personal data stays purposeful.

No advertising, sale of data, or unrelated use. No automated sharing or deletion.

Useful, not a guarantee.
